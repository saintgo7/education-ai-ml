# 종합 데이터 과학 프로젝트 (Capstone)

## 프로젝트 개요

Tier 1-2의 모든 기술을 활용한 실제 데이터 분석 프로젝트

## 필수 모듈

- 모듈 1-30 (30개)

## 학습 목표

- 실제 데이터셋 분석 및 정제
- 다양한 ML 알고리즘 적용
- 모델 비교 및 평가
- 결과 시각화 및 보고서 작성
