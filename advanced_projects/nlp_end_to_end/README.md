# NLP 엔드-투-엔드 프로젝트

## 프로젝트 개요

텍스트 수집부터 배포까지 전체 NLP 파이프라인 구축

## 필수 모듈

- 모듈 51-65 (15개)

## 학습 목표

- 텍스트 데이터 수집 및 정제
- 임베딩 생성 및 표현
- 모델 학습 및 튜닝
- 배포 준비
